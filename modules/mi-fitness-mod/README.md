# 📱 Mi Fitness MOD v4 (Health & Wear OS Unlocker)

Модифицированная версия официального приложения Mi Fitness с полным снятием региональных и аппаратных ограничений для китайских прошивок (OriginOS / ColorOS / HyperOS CN).

## 🚀 Что разблокировано в моде:
1. **Снятие фильтра Wear OS (`filterWearOS`)**:
   Официальный Mi Fitness на китайских прошивках намеренно скрывает глобальные часы на Wear OS. В данном моде метод проверки декомпилирован и нейтрализован — любые часы Wear OS подтягиваются из облака Xiaomi Cloud и отображаются во вкладке «Устройство».
2. **Медицинские алгоритмы высокого разрешения**:
   * **ЭКГ (ECG)**: Разблокированы графики электрокардиограммы миллисекундного разрешения.
   * **Аритмия**: Активирован алгоритм детекции фибрилляции предсердий (AFib).
   * **Здоровье сосудов**: Анализ жесткости артериального русла и пульсовой волны.
   * **Температура кожи**: Построение суточных температурных графиков.
   * **Артериальное давление**: Мониторинг давления и калибровка манжетой.

## 📦 Установка на смартфон:
Запустите `install_phone_mod.bat` при подключенном по USB смартфоне с включенной «Отладкой по USB».
