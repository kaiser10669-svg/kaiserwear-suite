🧠 Архитектура: Как работает Zero-Reset Pairing?

В китайских прошивках сервисы Google Play лишены модуля Wearable.API, поэтому сопряжение «с нуля» через «+» в приложениях вендоров не находит часы.

Универсальное решение: Мы переводим любые часы Wear OS в системный режим переноса без стирания памяти (WATCH_TRANSFER), спариваем Bluetooth, а затем снимаем зависший экран приветствия прямой командой финализации конфигурации user_setup_complete 1.

⚡ Сопряжение часов за 3 минуты

  1. Включите на часах: Настройки → Для разработчиков → Отладка по Wi-Fi.
  2. Запустите скрипт pair_watch_pc.bat из папки комплекса и введите IP часов.
  3. Подтвердите перенос на экране часов галочкой [✓] и сопряжение Bluetooth на смартфоне.
  4. Когда на часах появится надпись «Продолжите на телефоне», нажмите пробел в окне консоли ПК — скрипт сам отправит команды фикса.
  5. На часах свайпом вниз нажмите «Позже». Часы моментально выходят на циферблат!
  1. Установите на смартфон приложение Bugjaeger.
  2. Включите на часах «Отладку по Wi-Fi», подключитесь в Bugjaeger к IP часов.
  3. Во вкладке Commands отправьте команду переноса:
am start -a android.settings.WATCH_TRANSFER
  1. Подтвердите перенос на часах галочкой [✓] и сопряжение на телефоне.
  2. Когда на часах появится экран «Продолжите на телефоне», отправьте команды фикса:
settings put secure user_setup_complete 1 am start -a android.intent.action.MAIN -c android.intent.category.HOME
  1. На часах свайпом вниз нажмите «Позже» — готово!

📦 Фирменные модули комплекса

1. Kaiser Link: Беспроводной мост Wi-Fi (до 40 МБ/с)

Скоростная передача музыки (.mp3) и файлов на любые часы Wear OS по Wi-Fi. Вырезаны системные паразитные вибрации, передача целых альбомов занимает секунды.

2. Health & Sensor Unlocker

Модуль для Mi Fitness MOD v4, разблокирующий отображение часов на OriginOS (снят filterWearOS), графики ЭКГ высокого разрешения, детекцию мерцательной аритмии и давление.

3. WatchThermometer

Нативный виджет и осложнение для циферблата часов для чтения физических термодатчиков.

Разработано с душой для сообщества 4PDA, XDA и владельцев любых часов Wear OS.
